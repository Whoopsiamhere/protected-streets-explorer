# NYC Protected Streets — editable interactive site

Open `index.html` from a local web server, or use `standalone.html` directly in Chrome/Edge.

## Files you can edit
- `index.html` — page text and structure
- `styles.css` — colors, spacing, typography, layout
- `app.js` — map, filters, borough comparison, record list, interactions
- `data/streets.js` — prepared 24,404 active records used by the page

The public-facing page intentionally keeps only one source link and removes the prototype/method/cleaning-trail sections.
